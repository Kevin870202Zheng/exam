## 1. 考试事实

| 项目 | 内容 |
|---|---|
| 全称 | Licensing Examination for Securities and Futures Intermediaries — **Paper 7 Financial Markets** |
| 性质 | 实务卷（Practical），几乎所有受规管活动（Type 1/2/4/5/6/9 等）都要考 |
| 题量 | **60 题，四选一**，答错不扣分 |
| 时长 | **90 分钟**（平均 90 秒/题） |
| 合格 | **70%，即答对 42 题** |
| 形式 | 机考（CBE），香港考场每月开考 |
| 语言 | 英文 / 繁体中文（可申请简体版试卷，报名时确认） |
| 费用 | 香港考场 **HK$1,800**；全球考场 HK$2,250（官方把 Papers 1 & 7 归为同一档，高于 papers 8–12 的 HK$1,620/2,070） |
| 近年合格率 | 约 67% |

## 3. 备考路径（假设你有 4–6 周）

### 第 1 步：摸底（1 天，2 小时）
1. 打开 `source/p7-sample-chi.pdf`，**限时 90 分钟**做完整 60 题，不查书。
2. 对答案（PDF 最后一页），算分。
3. 打开 `04-官方样题60题考点地图.md`，把错的题按课题归类，看自己哪章最烂。

> 首刷 30–45 分是正常的。这一步只为了知道时间花在哪。

### 第 2 步：系统学（2–3 周，每天 1–1.5 小时）
按 **Topic 3 → 4 → 5 → 2 → 1 → 6 → 7** 的顺序（先高分章，后低分章）。

每章：
- 读开源教材对应章节 `source/ref-github-hksi-paper7/02-chapters/`（中文，零基础友好，每章 20 题 + 解析）
- 读手册（官方付费版）对应章
- 做该章 20 题，错题回去补

### 第 3 步：计算专项（3–4 天）
Paper 7 的计算题约占 7%（4–5 题），但**会做的和不会的差距最大**——这几题基本是白送分。

- 背 `02-必背数字与公式.md` 的公式区
- 做 `source/ref-github-hksi-paper7/03-calculations/04-drills.md`（30 道计算专项 + 解析）

### 第 4 步：冲刺（考前 1 周）
1. `02-必背数字与公式.md` + `03-易混淆对照表.md` 每天过一遍（各 15 分钟）
2. 做 2 套完整模拟卷：`source/ref-github-hksi-paper7/06-exams/`，限时 90 分钟，**目标 ≥ 80%**（留 10% 缓冲给真考的陌生题）
3. 考前 3 天把 `01-考纲与权重.md` 的自查表全部打勾

### 时间不够（只剩 3 天）
只看 `02` + `03` + 做完官方 60 题并读通解析 + 一个模拟卷。**放弃"通读教材"，只攻高频考点。**

## 5. 三条考试技巧

1. **先扫后做**：第一遍只做有把握的题（约 40 题，30 分钟），标记不确定的，第二遍回来攻。剩 10 分钟复查答案卡。
2. **看问法的关键字**：`除了 / 不正確 / 最不 / 最適合` —— 中式考卷最常见的失分点，不是不会，是看漏一个字。
3. **单选题组合（I, II, III）用排除法**：只要确定其中一项必错，就能砍掉一半选项，不必逐项验证。
